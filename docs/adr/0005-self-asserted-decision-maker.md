# 決策者身分為自述，不做認證

Gate 的 Human Decision 與 Human Review 都保存決策者身分，預設取自 Git 的 `user.email`，可覆寫。這個欄位是**聲明**，不是認證結果——ForgePilot 不驗證執行者是誰，也不驗證那是不是人。

不記錄身分會丟掉紀錄最有用的一半：三個月後回頭看，「有人選了 B」和「carl 選了 B」的價值差很遠。做真正的認證則與產品的其他部分矛盾——state 已經明文「不宣稱具有防竄改或身份認證能力」，而一個看起來像認證卻不是的機制，比完全不做更危險，因為它會讓讀者以為那個名字有保證。

此條特別記錄，是因為日後一定有人提議把它升級成認證。要不要升級取決於信任模型是否改變（例如 state 開始被多人共享或跨機器同步），而不取決於「加上認證比較嚴謹」。

**Falsified if:** state 不再是單一使用者的本機信任資料——`internal/storage/storage.go` 的 state 開始被多個身分共享或跨機器同步。屆時自述身分不再足夠，欄位語意必須連同信任模型一起重新設計。
