# 教學筆記

## 使用者

- 這個專案的作者。核心名詞、11 份 ADR、程式碼分層都不需要重講——直接從操作開始。
- 偏好結論先行、散文為主、少用條列與標題。教材可以密一點，不必鋪陳。
- 繁體中文（台灣用語）。

## 教法

- 教材是單一份手冊，不是一疊課。每一節都要**真的跑指令**，手冊裡的輸出全部是實跑貼上來的，不是我寫出來的範例。
- 使用者已經知道「為什麼」，所以知識段落壓到最短，重心放在 retrieval practice 與真實操作。
- 這個工具的價值在於擋人，所以流程本身就要走過每一個擋點，而不是只走順風路徑。

## 待觀察

- 作者對自己設計的東西可能有 fluency 的錯覺——知道規則不等於操作時想得起來。測驗要考「這個情況下會發生什麼」，不要考「這個名詞的定義」。
